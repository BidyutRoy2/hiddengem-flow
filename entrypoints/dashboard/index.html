Floating window

Click the HiddenGem Flow toolbar icon on any website to open the draggable floating window. Drag it by its header — its position is remembered.

The window runs in a Shadow DOM, so the site's own styles cannot break it.

What this extension does

Daily Tasks — save the sites you open every day and open them all in one click. Scripts — a userscript manager: write or import scripts, scan them, and run them on the sites they match. Script Store — the Official Store on GitHub: load it, search it, install a script with one confirm. Logs — per-tab status for every tab the extension opens, with Stop All.

Daily Tasks

Save the websites you open every day, by name and URL. Click a site to open it in a new tab, tick several and open them together, or open them all at once — each in its own tab. The first tab opens in front; the rest open in the background. Export them all to one JSON file, or import a backup the same way — importing merges, it never deletes what you already have.

    Scripts

    This site already has an official script — add it in one click from Script Store.

    A userscript manager: create, import, run, back up, delete and upgrade userscripts. Scripts run through Chrome's chrome.userScripts API — only on pages where you enable them, and only on the sites their @match lines name. Chrome also needs site access for those sites (a registered script without it never runs): click Grant site access on the script below, or set Site access → On all sites in the extension details.

    User scripts are not enabled yet.

    The userScripts permission alone is not enough — Chrome also needs you to flip a per-extension toggle:

    1. Open chrome://extensions
    2. Find HiddenGem Flow → Details
    3. Turn Allow User Scripts ON
    4. Reload this page — and reload any page where you want scripts to run

    Without that toggle, scripts are saved but never run, and nothing fails silently — this banner stays until the toggle is on. The button below only opens the Details page; no extension can flip the toggle for you.

    GM functions that actually work: GM_setValue, GM_getValue, GM_notification, GM_addStyle (and the GM.* object form). Not supported: GM_xmlhttpRequest, GM_openInTab, GM_download, GM_setClipboard, unsafeWindow and every other GM_* function — a script that calls one gets a scanner warning at install and a runtime error on the page, never a fake that pretends to work. GM values are stored in the page origin's localStorage, namespaced per script — the page can read them, so never store secrets with GM_*. Only JavaScript userscripts can run in a browser page: a file in another language can be opened here to inspect it, but it cannot run as a script.

        Logs — multi-tab runs

        Every tab this extension opens (Open All, Open Selected, or a single task click) gets a run entry: which installed scripts match that URL, and whether the tab finished loading. The list refreshes live while this tab is open.

        What “running” means: chrome.userScripts registration is per-extension, not per-tab — a run is “running” when the matching scripts are registered and the tab was opened by this extension. It does not prove the scripts executed inside the tab, it does not control other tabs, and it does not track tabs you opened yourself. “Stop All” marks the running runs stopped and closes only the tabs this extension opened in those runs, on a best-effort basis. The last 50 runs are kept.

          Settings

          Storage keys used by HiddenGem Flow (all in chrome.storage.local):

          • hiddengemflow.floating.pos — floating window position
          • hiddengemflow.tasks.v1 — saved task sites (Phase 2)
          • hiddengemflow.scripts.v1 — installed scripts (Phase 3)
          • hiddengemflow.scripts.errors.v1 — per-script registration errors (Phase 3)
          • hiddengemflow.store.cache.v1 — last good Official Store index + when it was fetched (Phase 4)
          • hiddengemflow.bridge.dismissed.v1 — hostnames where the store bridge banner was dismissed (Phase 4)
          • hiddengemflow.runs.v1 — multi-tab run log, last 50 runs (Phase 4)
          • hiddengemflow.update.v1 — latest release check result + when it was checked (update checker)

          Permissions in use: storage, tabs, scripting, activeTab, userScripts, notifications. No required host permissions — the floating window is injected only when you click the toolbar icon.

          • Scripts need two more grants, both yours to give. First, Chrome's per-extension Allow User Scripts toggle (chrome://extensions → HiddenGem Flow → Details) — no extension can flip it for you; the floating window has a button that opens that page directly. Second, site access for the sites a script runs on — an optional permission (*://*/*) granted per site (Scripts tab → Grant site access, or Site access → On all sites in the extension details). Until both are on, scripts are saved but never run.
          • Notifications are used only by GM_notification from a running script. Alarms was removed in v1.0.0 — it was requested but never used.

          Network: almost everything is user-triggered — nothing is sent to any server except (1) the best-effort favicon image (Google s2) shown next to each task site — a letter tile shows instead if it fails; (2) a script import from a URL, fetched once when you click Fetch, and the page you fetch can see the request; (3) Load store, which fetches the Official Store index (raw.githubusercontent, then jsDelivr), and opening a store script's detail view, which fetches its code once. The Smart Notification Bridge never fetches on its own — it reads the cached store copy. No analytics, no telemetry. The run log only records tabs this extension opened. The one exception is the update checker: it asks api.github.com for the latest release at most once every 6 hours (on startup/install and when this dashboard opens), plus whenever you click Check for updates below. It sends no data about you — the request is a plain public release listing.

          Extension updates

          This extension was installed unpacked, so Chrome never updates it by itself. A newer build is only ever noticed here — the update itself stays manual (download the new build, replace the files in your unpacked extension folder, press Reload in chrome://extensions; do not remove the extension). The checker asks GitHub for the latest release at most once every 6 hours, and shows a banner on the Overview tab when a newer build exists.
